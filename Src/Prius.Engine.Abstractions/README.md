# Prius.Engine.Abstractions

Абстрактный слой движка, определяющий интерфейсы взаимодействия компонентов системы без привязки к конкретным реализациям.

## Основные контракты

- **`IReactor`**: Базовый интерфейс реактора — компонента, обрабатывающего операции чтения/записи по определенному пути в иерархии данных.
- **`IReactorContext`**: Контекст выполнения операции в системе, предоставляющий доступ к окружению (`Env`) и методам диспетчеризации.
- **`IDataIntentsRegistry` / `IDataIntentsProvider`**: Механизм регистрации и обработки намерений (intents) для выполнения асинхронных операций с данными (RavenDB).
- **`IBinaryManager` / `IBinaryAccessor`**: Интерфейсы для управления бинарными данными (вложениями), поддерживающие хранение, удаление и потоковый доступ.
- **`ITimeProvider`**: Абстракция времени для тестируемости и детерминированного поведения компонентов.

## Намерения (Intents)
Набор типов `record`, представляющих декларативные операции (Load, Query, Store, Patch, Delete и т.д.), используемые системой для передачи задач от бизнес-логики к слою данных.
