# Prius.Engine.Abstractions

Абстрактный слой движка, определяющий интерфейсы взаимодействия компонентов системы без привязки к конкретным реализациям.

## Основные контракты

- **`IPriusModule`**: Интерфейс модуля системы. Управляет конфигурацией сервисов и жизненным циклом (`Activate`, `Stasis`).
- **`IElement`**: Компонент, обрабатывающий операции чтения/записи по заданному пути.
- **`IElementContext`**: Контекст выполнения, предоставляющий доступ к окружению (`Env`) и методам диспетчеризации.
- **`IBootstrapRuntime`**: Абстракция рантайма для загрузки сборок и ресурсов, обеспечивающая изолированную среду исполнения.

## Работа с данными и намерения (Intents)
- **`IDataIntentsRegistry` / `IDataIntentsProvider`**: Механизм регистрации и обработки асинхронных операций с данными (intents). Реестр поддерживает режим стазиса (`EnterStasis`), блокирующий новые интенты.
- **`IIntent`**: Базовый интерфейс декларативной операции (Load, Query, Store, Patch, Delete и т.д.).
- **`IBinaryManager` / `IBinaryAccessor`**: Управление бинарными потоками (вложениями).
- **`IPackageRepository`**: Хранилище метаданных пакетов, поддерживающее переходы состояний (`OnTransitionToStasis`, `OnTransitionToActive`, `OnTransitionToTerminated`).

## Утилиты
- **`ITimeProvider`**: Абстракция времени для детерминированного поведения.
- **`FrameworkConstants`**: Утилиты для работы с TFM (Target Framework Moniker).
- **`PathEnumerator`**: Вспомогательный класс для итерации по иерархическим путям (`MapPath`).
