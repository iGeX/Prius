# Prius.Engine

Реализация ядра движка Prius, ответственного за маршрутизацию операций и управление жизненным циклом данных.

## Маршрутизация и исполнение
- **`RoutingTrie`**: Префиксное дерево (Trie) для высокопроизводительного резолва реакторов по путям (`MapPath`). Поддерживает точное совпадение, одинарный (`*`) и глубокий (`**`) вайлдкарды.
- **`VirtualBus`**: Центральная шина, связывающая контексты выполнения с маршрутами. Обеспечивает кеширование резолвов и диспетчеризацию вызовов.
- **`ReactorContext`**: Конкретная реализация контекста, связывающая путь и окружение (`Env`) для текущей операции.

## Бинарные данные
- **`BinaryManager`**: Управление бинарными потоками с кешированием в памяти и вытеснением на диск при достижении лимитов. Автоматически управляет временными файлами и жизненным циклом узлов.

## Обработка данных
- **`DataIntentsRegistry`**: Реализация реестра намерений на базе каналов (`System.Threading.Channels`), обеспечивающая асинхронную очередь задач между потоками системы.
- **`EmptyReactor`**: Заглушка (Null Object), предотвращающая падения при обращении к несуществующим путям в дереве маршрутизации.
