# Prius.Data.RavenDB

Адаптер для интеграции с RavenDB в качестве основного хранилища данных. Реализует паттерн обработки намерений (Intents) для работы с базой данных.

## Обработка данных
- **`DataIntentsProcessor`**: Главный цикл обработки, слушающий очередь намерений (`Load`, `Query`, `Store`, `Patch`, `Delete` и т.д.) и транслирующий их в команды RavenDB. Реализует механизмы повторных попыток (retries) и обработки фатальных исключений.
- **`RqlBuilder`**: Декларативный компилятор, транслирующий `QueryMap` в RQL-запросы. Обеспечивает безопасность через нормализацию путей и параметризацию запросов.

## Управление инфраструктурой
- **`DocumentStoreHolder`**: Потокобезопасный провайдер `IDocumentStore` с поддержкой динамического обновления сертификатов и конфигураций подключения.

## Специфические функции
- **ID Materialization**: Обеспечивает детерминированное создание составных идентификаторов для результатов Map-Reduce запросов.
- **Parallel Processing**: Реализует эффективное извлечение метаданных Lucene и связанных документов напрямую из HTTP-потока RavenDB.
- **Attachments**: Интеграция с `IBinaryManager` для потоковой передачи вложений в RavenDB.
